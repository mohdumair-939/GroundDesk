# Application crashes, freezes, or shows "Not responding"

Use this guide when a program (for example Word, Excel, a browser, or a specialist application) closes unexpectedly, freezes with "Not responding", or will not start.

## The application is frozen

1. Wait one to two minutes; it may be saving or processing a large file.
2. Press Ctrl + Shift + Esc to open Task Manager, select the application, and click **End task**.
3. Open the application again. Office apps usually offer to recover unsaved documents in the **Document Recovery** pane.

## The application crashes repeatedly

1. Restart the computer.
2. Install updates for the application (Office: File > Account > Update Options > Update Now) and for Windows.
3. Check whether the crash happens with one specific file. If so, the file may be corrupted: try opening a copy, or use **Open and Repair** in Office (File > Open > select file > arrow next to Open > Open and Repair).
4. For Office apps, start in safe mode (for example `winword /safe` or `excel /safe` from Windows + R) and disable add-ins if safe mode works.
5. Repair the application: Settings > Apps > Installed apps > select the app > **Modify** or **Repair**.
6. If repair does not help, uninstall the app and reinstall it from the Software Center.

## Browser crashes

1. Update the browser to the latest version.
2. Disable extensions, then re-enable them one by one.
3. Clear the cache and cookies.

## When to escalate

Escalate if the application still crashes after a repair and reinstall, or if several different applications crash (that may point to a Windows or hardware problem; see the blue screen guide). Include the application name, version, and what you were doing when it crashed.
