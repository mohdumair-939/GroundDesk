# OneDrive or SharePoint files are not syncing

Use this guide when files in OneDrive or a synced SharePoint library do not update, show a red X or a "sync pending" icon, you see "You're not signed in to OneDrive", or a colleague cannot see changes you saved.

## Quick checks

1. Click the OneDrive cloud icon next to the clock. It shows whether sync is paused, signed out or has errors.
2. If sync is **paused**, choose **Resume syncing**.
3. Check you are online: open `https://www.office.com` in a browser.
4. Check free disk space on the computer. OneDrive stops syncing when the disk is nearly full (see the disk full guide).

## Fix sync problems

1. If OneDrive says you are signed out, click **Sign in** and use your work account with MFA.
2. Open the OneDrive icon > **View sync problems** and follow the suggestion for each file.
3. Close the file in every app. Files open in Office apps sync only after they are saved and closed.
4. Rename files with characters OneDrive does not allow (`" * : < > ? / \ |`) or names that are very long. The full path must stay under 400 characters.
5. Restart OneDrive: click the icon > settings gear > **Quit OneDrive**, then open **OneDrive** from the Start menu.
6. Restart the computer.

## Files show as "online-only" and will not open offline

Right-click the file or folder and choose **Always keep on this device**. It downloads and stays available without internet.

## Conflicting copies

If you see a copy with your computer name in the file name, two versions were saved at the same time. Open both, keep the correct content in the original file, then delete the copy.

## Restore a deleted or overwritten file

1. Open `https://www.office.com` > **OneDrive** (or the SharePoint site) in a browser.
2. Deleted files are in the **Recycle bin** for 93 days.
3. For an overwritten file, right-click it > **Version history** and restore an earlier version.

## When to escalate

Escalate if OneDrive shows an error code, if a whole SharePoint library stopped syncing for several people, or if your storage is full. Include the error code and the folder path.
