# External monitor or projector not detected

Use this guide when a second monitor, docking station display, or classroom projector shows "No signal", is not detected, displays the wrong resolution, or the picture is stretched or blurry.

## No signal or not detected

1. Check that the monitor or projector is switched on and set to the right input source (HDMI, DisplayPort or USB-C) using its own Input/Source button.
2. Check both ends of the cable and try a different cable if available.
3. Press **Windows + P** and choose **Duplicate** or **Extend**.
4. Open Settings > System > Display and click **Detect** under Multiple displays.
5. If you use a docking station, unplug the dock's power for 30 seconds, plug it back in, then reconnect the laptop.
6. Restart the computer with the display connected.

## Classroom projectors

1. Turn on the projector with the wall panel or remote and wait about one minute for it to warm up.
2. Select the matching input (for example HDMI 1 for the lectern cable).
3. Use **Windows + P** > Duplicate so the same image appears on the laptop and projector.

## Wrong resolution, stretched or blurry picture

1. Open Settings > System > Display, select the external display, and choose the **Recommended** display resolution.
2. Set Scale to the recommended value.
3. Update graphics drivers through Windows Update > Optional updates.

## Flickering

Flickering usually comes from a loose or damaged cable. Reseat or replace the cable, and avoid long HDMI adapters chained together.

## When to escalate

Escalate if the display works with another laptop but not yours (graphics driver or port issue), or if the monitor shows no image with any computer (faulty monitor). Include the monitor or projector location and model.
