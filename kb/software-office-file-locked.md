# Office file is locked, read-only or will not open

Use this guide when a Word, Excel or PowerPoint file says "is locked for editing by another user", opens as **Read-Only** or in **Protected View**, shows "upload failed", or Office reports the file is corrupt.

## "Locked for editing by another user"

1. If the file is in OneDrive, SharePoint or Teams, open it from there in the desktop app or the browser. Several people can edit at the same time; the lock message usually means the file is opened from a mapped or downloaded copy instead.
2. If the name shown is your own, the file is still open on another computer or in a hidden Office process. Close Office on all your devices, or restart the computer.
3. On a shared network drive, only one person can edit at a time. Ask the person named to close the file, or choose **Notify** to get a message when it is free.
4. If nobody has it open, wait 10 minutes; the lock expires on its own.

## Opens as Read-Only or in Protected View

1. Click **Enable Editing** on the yellow bar. Files from email and the internet open in Protected View for safety.
2. If the yellow bar says **Read-Only** and the file is on a shared drive or SharePoint, you may only have view access. See the shared file permission guide.
3. Right-click the file > **Properties** and clear **Read-only** if it is ticked (for files on your own computer).

## "Upload failed" or "Upload blocked"

1. Click **Save a copy** to keep your changes safe.
2. Sign in again in the Office app (**File** > **Account**).
3. Check OneDrive is running and syncing (see the OneDrive sync guide).

## File will not open or is corrupt

1. In the Office app, choose **File** > **Open** > **Browse**, select the file, click the arrow next to **Open** and choose **Open and Repair**.
2. For files in OneDrive or SharePoint, use **Version history** to restore the last good version.
3. Excel and Word may also list unsaved copies under **File** > **Info** > **Manage Workbook** or **Manage Document**.

## When to escalate

Escalate if an important file cannot be repaired and has no earlier version, or if many files on a shared drive are locked or will not open at once. Report straight away if file names have changed to strange extensions or a ransom note appears; disconnect from the network and do not open other files.
