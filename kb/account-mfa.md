# Multi-factor authentication (MFA) problems or new phone

Use this guide when you do not receive the MFA prompt, the authenticator code is rejected, or you have a new or lost phone.

## Not receiving the MFA prompt

1. Open the authenticator app on your phone; pending requests often appear only when the app is open.
2. Check that the phone has internet access (mobile data or Wi-Fi).
3. Make sure notifications are allowed for the authenticator app in the phone settings.
4. Use the **Enter a code** option on the sign-in screen and type the 6-digit code shown in the app instead.

## Code is rejected

1. The code changes every 30 seconds; type the current one quickly.
2. Codes depend on the phone clock. Set the phone date and time to **automatic**.
3. Make sure you are using the entry for your work account, not a personal account, in the app.

## New phone (old phone still available)

1. Sign in to `https://mysignins.helpdesk.local` > **Security info** using your old phone for approval.
2. Choose **Add sign-in method** > **Authenticator app** and scan the QR code with the new phone.
3. Set the new phone as the default method, then delete the old phone entry.

## Lost phone or no access to old phone

1. Raise a ticket immediately so the lost device can be removed from your account.
2. The service desk will verify your identity (ID card in person or a video call) and issue a one-time temporary access pass.
3. Use the pass to sign in to Security info and register your new phone.

## Unexpected MFA prompts

If you receive MFA prompts you did not start, **deny them** and change your password straight away; someone may know your password. Report it as a security issue.
