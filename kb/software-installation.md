# Install or request new software

Use this guide when you need to install an application, an installation fails, or you see "You need administrator permission" when installing.

## Install approved software from the Software Center

1. Open the Start menu and search for **Software Center**.
2. Browse or search the **Applications** tab for the software you need (for example Zoom, Python, VS Code, Adobe Reader, MATLAB).
3. Select it and click **Install**. You do not need administrator rights for software in the Software Center.
4. Keep the computer on and connected (VPN if remote) until the status shows **Installed**.
5. Restart if the Software Center asks you to.

## Installation fails in the Software Center

1. Restart the computer and try again.
2. Check you have at least 10 GB of free disk space (see the disk full guide).
3. Connect to the internal network or VPN; the Software Center downloads from internal servers.
4. If it still fails, note the error code shown (for example `0x87D00607`) and raise a ticket with it.

## Software not in the Software Center

1. Standard users cannot install software from the internet because it needs administrator rights.
2. Raise a ticket with the software name, version, a download link, the reason you need it, and whether it needs a paid licence.
3. IT checks the software for security and licensing, usually within 3 working days, then adds it to the Software Center or installs it for you.

## Browser extensions and personal software

Browser extensions from the official store are allowed if they do not access work data. Do not install pirated or "cracked" software; it is a common source of malware.
