# Web browser is slow, crashes or a website will not load

Use this guide when Microsoft Edge or Google Chrome is very slow, freezes or crashes, a company website shows a blank page or keeps loading, buttons do nothing, or a site works for colleagues but not for you.

## A website will not load or looks broken

1. Reload the page with **Ctrl+F5** (Cmd+Shift+R on a Mac) to skip the cached copy.
2. Open the site in a private (InPrivate or Incognito) window. If it works there, clear the browser cache and cookies: settings > **Privacy** > **Clear browsing data**, choose **Cached images and files** and **Cookies**, time range **All time**.
3. Try the other company browser (Edge or Chrome).
4. Internal sites (addresses ending in `helpdesk.local`) only work on the company network or the VPN.
5. If no website loads at all, see the slow internet and Wi-Fi guides.

## Browser is slow or uses a lot of memory

1. Close tabs you do not need. Each tab uses memory.
2. Open the browser's task manager (**Shift+Esc**) to find a tab or extension using a lot of memory, and end it.
3. Turn off extensions you do not use: settings > **Extensions**. A broken extension is a common cause of slowness and crashes.
4. Update the browser: settings > **About**. Restart it when asked.

## Browser keeps crashing

1. Restart the computer.
2. Turn off all extensions, then turn them back on one at a time to find the faulty one.
3. Turn off **Use graphics acceleration when available** in settings > **System**, then restart the browser.
4. Create a new browser profile to rule out a damaged profile. Sign in to it so your bookmarks sync back.

## Pop-ups, downloads or file uploads blocked

Click the icon at the right of the address bar to allow pop-ups for that site. If a download is blocked as unsafe and you trust the source, raise a ticket rather than bypassing the warning.

## When to escalate

Escalate if a company web app fails in both browsers after clearing the cache, or if the browser shows unwanted ads, a changed home page or search engine, or extensions you did not install. These can be signs of unwanted software.
