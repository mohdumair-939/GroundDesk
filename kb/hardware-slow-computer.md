# Computer is very slow or takes long to start

Use this guide when your computer takes a long time to start or sign in, programs open slowly, or the whole system lags.

## Quick fixes

1. **Restart the computer.** Choose Start > Power > **Restart** (not Shut down). Many computers are slow simply because they have not been restarted for weeks.
2. Install pending Windows and Office updates, then restart again.
3. Close programs and browser tabs you are not using.

## Find what is using resources

1. Press Ctrl + Shift + Esc to open Task Manager and click **Processes**.
2. Sort by **CPU**, **Memory** and **Disk** to see what is using the most.
3. End tasks for programs you do not need. Do not end Windows system processes.
4. Cloud sync tools and antivirus scans can slow the computer temporarily; let them finish.

## Speed up start-up

1. In Task Manager, open the **Startup apps** tab.
2. Disable apps you do not need at start-up (for example music players, game launchers, chat apps). Do not disable security software.

## Free up disk space

A nearly full disk makes the computer slow. Keep at least 15% of the C: drive free (see the disk full guide).

## Check power settings (laptops)

1. Plug in the charger. Laptops run slower on battery saver.
2. In Settings > System > Power & battery, set Power mode to **Balanced** or **Best performance**.

## Check for malware

Open **Windows Security** > Virus & threat protection > **Quick scan**. If anything is found, follow the steps shown and raise a ticket.

## When to escalate

Escalate if the computer is still slow after these steps, if Task Manager shows disk usage at 100% all the time, or if the computer is more than 5 years old; it may need a memory or SSD upgrade or replacement.
