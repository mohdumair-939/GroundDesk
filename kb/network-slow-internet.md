# Internet or network is very slow

Use this guide when web pages load slowly, downloads crawl, video calls freeze, or file transfers to network drives take much longer than usual.

## Find out where the slowness is

1. Run a speed test at a public speed-test site and note the download, upload and ping values.
2. Compare with a colleague on the same network. If everyone is slow, it is likely a network-wide issue: raise a ticket with your location and the speed-test result.
3. If only your device is slow, continue below.

## Fix slowness on your device

1. Close browser tabs and apps you are not using, especially video streaming and cloud sync tools (OneDrive, Google Drive, Dropbox) that may be uploading large files.
2. Pause cloud sync for a few hours if a large sync is running.
3. If you are on Wi-Fi, move closer to the access point or use a wired network cable.
4. Disconnect from the VPN when you do not need internal resources; all traffic through the VPN is slower.
5. Restart your computer to finish pending updates.
6. Run `ipconfig /flushdns` in Command Prompt to clear stale DNS entries.
7. Try a different browser. If only one browser is slow, clear its cache and disable extensions.

## At home

1. Restart your router and modem by unplugging them for 30 seconds.
2. Check whether other people in the house are streaming or downloading heavily.
3. Use the 5 GHz Wi-Fi band if your router offers it.

## When to escalate

Escalate with your speed-test results if the network is slow for everyone in an area, if wired speed is also slow, or if only internal systems (not the public internet) are slow.
